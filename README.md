# খেলাঘর (Khelaghor)

বাংলার ঐতিহ্যবাহী আর ভাইরাল গেমের অনলাইন গেমিং হাব।

## ফোল্ডার
- `index.html` — হাবের মূল পেজ (লবি, লগইন, দোকান, ডায়লগ)
- `games/ludo/` — লুডু (কম্পিউটারের সাথে)
- নতুন গেম যাবে `games/<game-name>/index.html` এ

## অবস্থা
এটা ডেমো। লগইন, পেমেন্ট আর অনলাইন মাল্টিপ্লেয়ার এখনো আসল সার্ভারে যুক্ত হয়নি।
কয়েন শুধু খেলার জন্য, টাকায় তোলা যায় না।
