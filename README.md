# খেলাঘর (Khelaghor)

বাংলার ঐতিহ্যবাহী আর ভাইরাল গেমের অনলাইন গেমিং হাব।

## ফোল্ডার
- `index.html` — হাবের মূল পেজ (লবি, লগইন, দোকান, ডায়লগ)
- `games/ludo/` — লুডু (কম্পিউটারের সাথে)
- নতুন গেম যাবে `games/<game-name>/index.html` এ

## অবস্থা
এটা ডেমো। লগইন, পেমেন্ট আর অনলাইন মাল্টিপ্লেয়ার এখনো আসল সার্ভারে যুক্ত হয়নি।
কয়েন শুধু খেলার জন্য, টাকায় তোলা যায় না।

## গেম তালিকা (৪৪টি)
১. লুডু ✅ · ২. মশা মারো · ৩. ঢাকা জ্যাম রানার · ৪. বাজার দর চ্যালেঞ্জ · ৫. আর্জেন্টিনা বনাম ব্রাজিল · ৬. হাইওয়ে রাজা ·
৭-২৪. ঐতিহ্যবাহী (ক্যারম, ষোলোগুটি, বাঘবন্দি, ঘুড়ি, হাডুডু, কলব্রিজ, টুয়েন্টি নাইন, দাবা, ...) ·
২৫-৪৪. ভাইরাল (লোকাল বাস হেলপার, লোডশেডিং, রিকশা ভাড়া, ...)

## অনলাইন সিস্টেম (Firebase: khelaghor-160)
- `js/firebase-config.js` — Firebase config, অ্যাডমিন Gmail, পয়েন্টের নিয়ম
- `js/online.js` — Gmail লগইন, ইউজারনেম, পয়েন্ট, দৈনিক বোনাস, লিডারবোর্ড, ইনভাইট, রুম
- `admin/` — অ্যাডমিন প্যানেল (পয়েন্ট দেওয়া/কাটা, সেরা খেলোয়াড়)
- `firestore.rules` — ডেটাবেসের নিরাপত্তা নিয়ম, Firebase Console → Firestore → Rules-এ পেস্ট করে Publish করতে হবে

## লুডু সার্ভার (`api/ludo.js`)
ছক্কা, চাল যাচাই, জয়-হার আর পয়েন্ট সব সার্ভারে হয় (Vercel Function), তাই ফোন থেকে কারচুপি সম্ভব না।
চালু করতে Vercel → Settings → Environment Variables-এ `FIREBASE_SERVICE_ACCOUNT` নামে
Firebase-এর service account JSON বসাতে হবে। নিয়ম আছে `js/ludo-engine.js`-এ।

## AI ভয়েস (`api/voice.js`)
মজার ডায়লগ Google Cloud Text-to-Speech-এর বাংলা কণ্ঠে বাজে, একবার তৈরি হয়ে ক্যাশে থাকে।
শুধু `api/_voice-lines.js`-এর লাইন বাজানো যায়। ডায়লগ বদলালে চালান: `node tools/build-voice-lines.mjs`
Google Cloud-এ Text-to-Speech API চালু না থাকলে ফোনের নিজের বাংলা কণ্ঠ ব্যবহার হয়।

## ফানি ভিডিও (`js/videos.js`)
অ্যাডমিন → সেটিংস → "ফানি ভিডিও"-তে YouTube/TikTok/Facebook লিংক দিলে `config/videos`-এ জমা হয়। হাবে স্ক্রল করলে ভিডিও নিজে চলে (শব্দ ছাড়া, ডাটা সেভার চালু থাকলে না), আর গেমের বিরতি/শেষ পর্দায় (`<div class="gvid">`) একটা ভিডিও দেখায়।

## ঢাকা জ্যাম রানার ৩ডি (`games/jam/`)
Three.js (`js/vendor/three.module.min.js`, r160, MIT)। ৫×৫ রাস্তার শহর: বাসা থেকে অফিস। মোড়ে লেন অনুযায়ী বামে/সোজা/ডানে, মোড়ে সিগন্যাল ও আড়াআড়ি গাড়ি, ছোট ম্যাপ, রাস্তার মানুষের কথা (বুদবুদ + সাবটাইটেল), হর্ন/বোমা/ক্যামেরা বোতাম।

## হাইওয়ে রাজা (`games/racer/`)
বাস্তবসম্মত ৩ডি হাইওয়ে রেস (Traffic Racer ধাঁচ): ঢাকা-চট্টগ্রাম মহাসড়ক, বাম দিকে চলাচল, ট্রাফিক লেন বদলায় ইন্ডিকেটর দিয়ে, কান ঘেঁষা বোনাস।
অ্যাসেট `games/racer/assets/` (প্রায় ৫MB): গাড়ি Khronos Car Concept (CC-BY 4.0, পেজে আর `CREDITS.txt`-এ ক্রেডিট আছে, লোগো সরানো),
আকাশ/HDR, পিচ, ঘাস, ব্যারিয়ার, গাছ Poly Haven (CC0)। মডেল বানানোর স্ক্রিপ্ট `tools/racer-car-asset.mjs`, `tools/racer-prop-asset.mjs`।
three-এর লোডার `js/vendor/addons/` (GLTFLoader, RGBELoader, BufferGeometryUtils, SkeletonUtils, meshopt_decoder)।

## লুডু দ্রুত কথা
`QUICK` তালিকা (`js/ludo-engine.js`) থেকে নম্বর পাঠানো হয় (`action: 'chat'`), সার্ভার শুধু তালিকার লাইন রাখে, ৩ সেকেন্ডে একবার।
